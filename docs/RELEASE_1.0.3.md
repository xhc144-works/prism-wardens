## 本次改动

- 版本递增为 1.0.3，保留已发布的 1.0.2 和所有历史标签。
- 发布前只在 Actions 内存中检查生产私钥类型及派生公钥，必须匹配既有内置 Ed25519 公钥。日志仅记录通过/失败，不导出私钥。
- 保留 SHA-512、Ed25519 和已配置的 Authenticode 校验；未配置 Windows 证书时仍允许 Ed25519 保护的更新。
- 增加独立的 `Verify published update` 手动工作流，以固定 SHA-256 的已发布 1.0.2 为起点，从真实 GitHub 地址完成发现、下载、签名验证及安装升级。它不接收生产私钥，不生成测试证书，不使用本地更新服务器，不改写历史安装包的更新地址或公钥，不向客户端传递 GitHub Token。
- 升级后检查版本、原生接口、主窗口、更新入口及用户数据保留，输出过滤下载 URL 的日志和验收 JSON。私有仓库会直接报告旧匿名客户端的认证阻塞。
